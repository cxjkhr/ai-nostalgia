# AI 怀旧服

交互式视觉 demo：2022—2025 年份切换、档案详情、预设聊天示例。

## 内容边界
聊天界面为编辑式重构，回答为预设演示文字，不连接真实模型。手记为原创演示文案，不冒充历史评论。精选节点并非完整年表。
